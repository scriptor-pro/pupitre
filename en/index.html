A terminal designed for accessibility first

Pupitre is a tabbed terminal emulator for Linux, on X11 and Wayland. Everything works from the keyboard, the Orca screen reader reads what is shown, and every colour theme is checked to stay readable.

Free software under the GPL-3.0 licence, written in Rust with GTK 4 and VTE.

The interface is in French for now; English and other languages are planned.

What Pupitre does

Accessibility

  • Everything works from the keyboard, menus and dialogs included.
  • Orca reads command output, announces when a long command (5 seconds or more) finishes, and lets you jump from one command to the next.
  • The light and dark themes meet a contrast ratio of at least 4.5:1 (WCAG AA). Pupitre also checks your own themes.
  • Steady cursor by default, zoomable text, readable fonts included: B612 Mono and Atkinson Hyperlegible Mono.

Robustness

  • Shells run in a process separate from the window: if the window crashes, your commands keep running and your tabs come back.
  • A mistake in the configuration file never crashes Pupitre: it keeps the previous settings and points to the faulty line.

SSH and shells

  • An SSH agent is always available to your shells; your key passphrase can be remembered in the system keyring.
  • Saved SSH connections, opened in a new tab.
  • A ready-to-use Starship prompt for bash, zsh, fish, nushell and elvish, without touching your own configuration files.

Privacy

  • No Internet connection: no update check, no crash report, no download.

Install

Pupitre needs Debian 13 (trixie) or later, or a distribution based on it: GTK 4.18 and VTE 0.80 at least.

  1. Download the Debian package (.deb file, 2.2 MB)

  2. In the folder that contains the file, install it:

    sudo apt install ./pupitre_0.1.0-1_amd64.deb

  3. Start Pupitre from the applications menu, or type pupitre.

Recommended: Starship, for the prompt, and a keyring (GNOME Keyring, KWallet or KeePassXC), to remember SSH passphrases. Pupitre works without them: each shell keeps its usual prompt and the passphrase is asked again.

Uninstall: sudo apt remove pupitre. Your settings, in ~/.config/pupitre/, are kept.

Essential shortcuts

Pupitre uses Ctrl+Shift for its own shortcuts: Ctrl alone is left to programs. Shortcuts follow the letters of your keyboard layout (QWERTY, AZERTY, Dvorak…).

Build from source

On Debian 13, install the tools and libraries:

sudo apt install build-essential pkg-config libgtk-4-dev libvte-2.91-gtk4-dev cargo

Then, in the source folder:

cargo build --release --locked

The programs are in target/release/. To build the Debian package: scripts/construire-deb.sh. Details are in the repository README file (en français).

Accessibility of this page

This page aims to conform to WCAG 2.2 level AA and to the French RGAA 4.1.2. It has not been audited externally.

Checks done: automated testing (axe-core), keyboard-only navigation, contrast of both themes, display at 200% zoom and on a 320-pixel-wide screen, increased text spacing.
