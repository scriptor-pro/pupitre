Un terminal pensé d'abord pour l'accessibilité

Pupitre est un émulateur de terminal à onglets pour Linux, sous X11 comme sous Wayland. Tout se fait au clavier, le lecteur d'écran Orca lit ce qui s'affiche, et chaque thème de couleurs est vérifié pour rester lisible.

Logiciel libre sous licence GPL-3.0, écrit en Rust avec GTK 4 et VTE.

Ce que fait Pupitre

Accessibilité

  • Tout se fait au clavier, menus et fenêtres compris.
  • Orca lit la sortie des commandes, annonce la fin des commandes longues (5 secondes ou plus) et permet d'aller d'une commande à l'autre.
  • Les thèmes clair et sombre respectent un contraste d'au moins 4,5:1 (WCAG AA). Pupitre vérifie aussi vos propres thèmes.
  • Curseur fixe par défaut, texte agrandissable, polices lisibles fournies : B612 Mono et Atkinson Hyperlegible Mono.

Robustesse

  • Les shells tournent dans un processus séparé de la fenêtre : si la fenêtre plante, vos commandes continuent et les onglets reviennent.
  • Une erreur dans le fichier de configuration ne fait jamais planter Pupitre : il garde les réglages précédents et indique la ligne fautive.

SSH et shells

  • Un agent SSH est toujours disponible pour vos shells ; la phrase de passe de votre clé peut être mémorisée dans le trousseau du système.
  • Connexions SSH mémorisées, ouvertes dans un nouvel onglet.
  • Invite Starship prête à l'emploi pour bash, zsh, fish, nushell et elvish, sans toucher à vos propres fichiers de configuration.

Vie privée

  • Aucune connexion à Internet : ni vérification de mise à jour, ni rapport de plantage, ni téléchargement.

Installer

Pupitre demande Debian 13 (trixie) ou plus récent, ou une distribution qui en dérive : GTK 4.18 et VTE 0.80 au minimum.

  1. Télécharger le paquet Debian (fichier .deb, 2,2 Mo)

  2. Dans le dossier où se trouve le fichier, installez-le :

    sudo apt install ./pupitre_0.1.0-1_amd64.deb

  3. Lancez Pupitre depuis le menu des applications, ou tapez pupitre.

Recommandés : Starship, pour l'invite, et un trousseau (GNOME Keyring, KWallet ou KeePassXC), pour mémoriser les phrases de passe SSH. Sans eux, Pupitre fonctionne : chaque shell garde son invite habituelle et la phrase de passe est redemandée.

Désinstaller : sudo apt remove pupitre. Vos réglages, dans ~/.config/pupitre/, restent en place.

Raccourcis essentiels

Pupitre utilise Ctrl+Maj pour ses propres raccourcis : Ctrl seul reste aux programmes. Les raccourcis suivent la lettre de votre disposition de clavier (AZERTY, BÉPO, Dvorak…).

Raccourcis clavier principaux de Pupitre
Action Raccourci
Ouvrir l'aide intégréeCtrl+Maj+H
Nouvel ongletCtrl+Maj+T
Fermer l'ongletCtrl+Maj+W
Copier, collerCtrl+Maj+C, Ctrl+Maj+V
Rechercher dans l'historiqueCtrl+Maj+F
Commande précédente, suivanteCtrl+Maj+↑, Ctrl+Maj+↓
Sortir du terminal vers les menus et ongletsCtrl+Tab
Connexions SSHCtrl+Maj+O
Agrandir, réduire le texteCtrl++, Ctrl+-

Compiler depuis les sources

Sous Debian 13, installez les outils et bibliothèques :

sudo apt install build-essential pkg-config libgtk-4-dev libvte-2.91-gtk4-dev cargo

Puis, dans le dossier des sources :

cargo build --release --locked

Les exécutables sont dans target/release/. Pour construire le paquet Debian : scripts/construire-deb.sh. Le détail est dans le fichier README du dépôt.

État du projet

Version 0.1 : Pupitre est jeune. Prévus ensuite : fenêtre de réglages, notifications, indicateur de disposition du clavier, thème à contraste élevé. L'interface est en français ; anglais, espagnol, italien, allemand et néerlandais suivront.

Code source, signalement de problèmes et suggestions : dépôt Pupitre sur GitHub.

Accessibilité de cette page

Cette page vise la conformité au niveau AA des WCAG 2.2 et au RGAA 4.1.2. Elle n'a pas fait l'objet d'un audit externe.

Vérifications faites : contrôle automatique (axe-core), navigation au clavier seul, contrastes des deux thèmes, affichage à 200 % et sur un écran de 320 pixels de large, espacement du texte agrandi.

Un problème d'accès ? Signalez-le dans les tickets du dépôt GitHub.
